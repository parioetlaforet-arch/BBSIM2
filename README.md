BBSIM 2.0
ブラウザ上で電子回路を組み立て、配線・動作・電気的な振る舞いを観察できるブレッドボード回路シミュレーター

BBSIM 2.0 は、ブレッドボード上に電子部品を配置し、ジャンパーワイヤーで接続しながら回路を組み立てる学習・実験向けのシミュレーターです。回路の通電状態だけでなく、電流経路や各部品の電圧降下などを画面上で確認できるよう設計しています。
開発状況：開発中／テストプレイ段階

現在、複数のテスターによる操作確認と不具合の洗い出しを予定しています。機能や画面構成、シミュレーションの挙動は今後変更される可能性があります。重要な用途や実機設計の判断には使用しないでください。

主な機能
- ブレッドボード上での回路構築 — 部品を配置し、穴同士をジャンパーワイヤーで接続して回路を組み立てられます。
- 複数の電子部品に対応 — 抵抗器、LED、コンデンサ、可変抵抗器、スイッチ（SPST／SPDT／タクト）、ダイオード、トランジスタ、MOSFET、CdSセル、ブザーなどを扱います。
- 回路状態の解析・表示 — 開放（OPEN）、導通（CLOSED）、短絡（SHORT）などの状態を判定し、画面に表示します。
- 電流経路・分圧ツリー — 電源からGNDまでの経路や、部品ごとの電圧降下・電流などを確認できます。
- リアルタイム・オシロスコープ表示 — 回路の電圧波形を画面上で観察できます。
- 回路プリセット／学習用課題 — 基本的なLED点灯回路や可変抵抗による調光回路、スイッチを使った回路など、用意された回路例を利用できます。
- 開発者向け監査機能 — ブラウザーの開発者ツール（F12）のコンソールから、プリセットや回路計算などの検証を行えます。
※対応部品や各機能の詳細、物理モデルの適用範囲は開発に伴い変更される場合があります。

起動方法
現行版はHTMLとJavaScriptで動作する構成です。ビルドツールやパッケージのインストールを必要としない形で利用できます。
1. このリポジトリをダウンロードするか、クローンします。
2. HTMLファイルと app.js を同じフォルダーに配置します。
3. HTMLファイルをブラウザーで開きます。
git clone <このリポジトリのURL>
クローン後、HTMLファイルをブラウザーで開いてください。GitHub上のファイル名・配置に合わせて、必要であればHTMLファイルを index.html に変更してください。
注意： HTML側では app.js を読み込む構成です。ファイル名やフォルダー構成を変更した場合は、HTML内の <script src="app.js"></script> も実際の配置に合わせて変更してください。

基本的な使い方
1. ブレッドボードに電子部品を配置します。
2. 部品の端子とブレッドボードの穴を確認します。
3. ジャンパーワイヤーで電源、部品、GNDなどを接続します。
4. スイッチや可変抵抗器などを操作し、回路の変化を確認します。
5. 電流経路・分圧ツリー、イベントログ、オシロスコープ表示を参考に、回路の状態を観察します。
最初は、プリセットに用意された基本LED点灯回路などから試すことをおすすめします。
テストプレイ・不具合報告
現在は、開発者以外の利用者にも操作してもらい、想定外の操作や環境で発生する不具合を確認する段階です。

不具合を報告する際は、可能な範囲で次の情報を添えてください。
- 使用OSとブラウザー名・バージョン
- 不具合が起きるまでの操作手順
- 実際に起きたこと
- 本来期待していた動作
- エラーメッセージ（表示された場合）
- スクリーンショットまたは画面録画（可能な場合）
不具合報告や機能提案は、GitHub の Issues からお願いします。再現できる操作手順をできるだけ具体的に記載してください。
既知の制限・注意事項
- 本ソフトウェアは学習・動作理解を目的としたシミュレーターです。実際の電子部品のばらつき、温度特性、寄生成分、電源の内部抵抗など、現実の回路で発生するすべての現象を再現するものではありません。
- シミュレーション結果を、実機の安全性や部品定格の判断にそのまま使用しないでください。
- 開発中のため、未発見の不具合や未実装の挙動が残っている可能性があります。
- 画面サイズやブラウザーによって表示・操作性に差が出る可能性があります。
